# Diagram labels and commit notes

This folder contains the port labels and instructions to update the existing draw.io network diagram.

Files added:
- labels.txt — plain text list of port assignments and diagram legend to apply to your draw.io diagram.
- network-diagram.drawio — a simple draw.io file containing a labeled text box you can import or copy into your diagram as-needed.
- README.md — short notes describing the change and where to place the labels.

Committed by Copilot on behalf of the repository owner. If you'd like the diagram to be edited in-place (pixel-perfect), please upload the original .drawio file from your local machine and I will modify it directly.
